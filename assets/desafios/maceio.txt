# Como editar (texto em UTF-8; linhas com # são comentários):
# - Cada desafio começa com o id entre colchetes, numa linha sozinha
#   (a missão aponta para ele no campo "desafio" de assets/missoes)
# - Campos, um por linha, no formato   campo: valor
#     conta:       a conta, com + - * /  (também aceita x para vezes e : para dividir)
#                  Ex.: 2 + 3   |   12 / 3   |   20 * 25 / 100   (vezes e dividir vêm antes)
#     dificuldade: 1 (fácil) a 3 (difícil)
#     contexto:    frase que explica a conta, mostrada depois que a missão é concluída
#     acao:        o que o jogador precisava fazer (descrição)
# - O RESULTADO da conta é a quantidade exata que a Lia precisa entregar na
#   missão que aponta para este desafio.
# - Divisões precisam dar resultado inteiro.

[cocos_graca]
conta: 20 * 25 / 100
dificuldade: 2
contexto: 25% de 20 é o mesmo que 1/4 de 20: são 5 cocos. Agora a Dona Graça tem 25 cocos para a tapioca da festa!
acao: entregar à Dona Graça 25% dos 20 cocos que ela tem

[lixo_bene]
conta: 18 / 3 * 4 - 18
dificuldade: 3
contexto: Se 18 é 3/4, então 1/4 é 6 e o lixo todo era 24. Faltavam 24 - 18 = 6 lixos. A praia está limpa para a Festa das Águas!
acao: recolher o lixo que faltava e entregar ao Seu Bené
